# Demo guide

Suggested rehearsal sequence, not a statement of the event's required video length.

## Opening

Show the workspace. Explain: “When a developer takes over an AI-assisted change, the diff alone does not tell them why it exists or what was checked. Memento packages the code, context and reported evidence into a portable handover.”

## Expose the risk

Open SignalGrid, choose Proposed change, and Verify change. Show the failed ownership checks. Explain that this is a controlled simulation: increasing retries recovers delivery while removing the claim permits duplicate operations.

Choose Review correction, inspect the preserved claim and verify again. Show four passing checks and the execution trace. Do not call this external-provider or distributed-system verification.

## Show actual Bob work

Open the router review. Show the original subtraction and corrected explicit status counts. Open Context and the required behaviour. Briefly show the genuine Bob task evidence for this correction. Avoid presenting Memento exports as Bob session summaries.

## Hand over

Open Checks: imported local command, exit zero, captured output reporting 32 assertions. Expand fingerprint details only if needed. Explain that Memento checks the content match but does not independently authenticate the run.

Export the review and import that JSON in a second browser workspace. Show restored context, code and evidence. This is the receiving developer's starting point.

## Close

“Memento keeps the reasoning and reported checks with the change, so the next maintainer has a reviewable starting point.”

Do not claim measured time savings, production adoption or guaranteed correctness. Record real interactions; do not simulate live execution with static success screens.
